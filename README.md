# MoneyMind

Ideia principal:

  A ideia principal do sistema, é ajudar os jovens a organizar sua vida financeira de maneira pratica, com a ajuda do python e o banco de dados para realizar o armazenamento e controle dos dados.

----

Tecnologias utilizadas:

° Python

° MySQL

° MySQL Connector

° Brmodelo

° GitHub

----

Funções:

°Cadastro de usuário

°Registro de receita

°Registro de despesas

°Total de saldo
